Bagaimana Algoritma Bekerja

Pipeline lengkap K-Means yang dijalankan oleh aplikasi.

Min-Max Normalization

Setiap fitur (harga, rating, terjual) di-skala ke [0, 1] dengan rumus x' = (x − x_min) / (x_max − x_min) agar tidak ada variabel yang mendominasi perhitungan jarak Euclidean.

Elbow Method

Untuk K = 2 sampai 7, hitung total inertia (within-cluster sum of squares). Titik di mana penurunan inertia mulai melandai disebut "elbow" — di sini K = 3.

Silhouette Score Validation

Silhouette Score mengukur seberapa mirip suatu data dengan cluster-nya sendiri (cohesion) dibandingkan cluster terdekat (separation). Skor mendekati 1 berarti pemisahan yang baik. Pada K=3, skor = {{ r.kmeans.silhouette_K3 }}.

K-Means Clustering (K = 3)

Inisialisasi 3 centroid via K-Means++, iterasi: assign tiap titik ke centroid terdekat → update centroid → ulangi sampai konvergen. random_state=42 untuk reproduksibilitas.

Pelabelan Bisnis

Cluster dengan rata-rata terjual tertinggi → Bestseller. Cluster dengan rata-rata harga tertinggi → Premium. Cluster lainnya → Regular.
