Lingkup Project

Project ini menganalisis 30 produk dari Crocs Official Store di Shopee Indonesia yang dikumpulkan via web scraping. Tujuannya adalah mengidentifikasi pola perilaku konsumen, segmen produk, dan hubungan antar variabel (harga, rating, diskon, promo, jumlah terjual).

Web Scraping K-Means Pearson Min-Max Silhouette EDA

Rumusan Masalah

  1. Bagaimana pola distribusi rating dan hubungan harga, diskon, dan jumlah terjual?
  2. Bagaimana segmentasi produk via K-Means berdasarkan harga, rating, dan volume?
  3. Sejauh mana pengaruh promosi dan diskon terhadap perilaku pembelian?

Pipeline Lengkap

6 tahap pipeline manajemen big data dari pengumpulan hingga visualisasi.

Pengumpulan Data — Web Scraping

Ekstraksi 30 produk dari halaman Crocs Official Store di shopee.co.id dengan atribut HTML. Disimpan sebagai shopee.xlsx.

Pembersihan Data

Rename kolom, parsing harga (titik ribuan), parsing terjual ("5RB+" → 5000), ekstraksi kategori dan warna, kalkulasi harga setelah diskon.

Penyimpanan Data

Multi-format: CSV bersih untuk analisis, Excel multi-sheet untuk dokumentasi, statistik deskriptif terpisah.

Pengolahan Data

Min-Max Normalization fitur clustering, Elbow Method, Silhouette Score, K-Means dengan K=3, pelabelan cluster (Bestseller / Premium / Regular).

Analisis Data

Statistik deskriptif, korelasi Pearson 4 variabel, segmentasi popularitas, analisis pengaruh promo, top-N produk.

Visualisasi & Aplikasi Web

Charts dengan matplotlib + seaborn (PNG), plus visualisasi interaktif berbasis Chart.js. Dashboard Flask sebagai presentation layer untuk hasil pipeline.
