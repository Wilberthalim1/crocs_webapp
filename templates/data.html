Tahap 1 — 3 · Pengumpulan, Pembersihan, Penyimpanan

Dari HTML scraping ke dataset bersih siap analisis.

Data mentah dikumpulkan via web scraping dari halaman Crocs Official Store di Shopee Indonesia. Kolom HTML yang asli (kelas CSS yang tidak deskriptif) di-rename, format harga "Rp989.000" dikonversi menjadi numerik, "5RB+ terjual" diparse menjadi 5000, dan kolom turunan seperti kategori, warna, dan harga setelah diskon di-ekstrak.

Pipeline Cleaning
{{ r.rows_clean }} rows

Rename kolom HTML → semantik

Kolom hasil scrape (contents href, font-medium 2, dll) di-rename menjadi nama yang deskriptif: nama_produk, harga, rating, terjual.

Parsing harga

"Rp989.000" → hapus titik ribuan → konversi numerik → 989000.

Parsing terjual

"5RB+ terjual" → ekstrak 5 → kalikan 1000 → 5000. "870 terjual" → 870.

Ekstraksi fitur turunan

Kategori (Kids, Women, Unisex, dll), warna (split " - "), harga setelah diskon, dan flag promo biner.

Penyimpanan multi-format

CSV (shopee_crocs_clean.csv) untuk analisis, Excel multi-sheet untuk dokumentasi, dan statistik deskriptif terpisah.
